## Acceptance Test Document — 事记本 V1（灵魂闭环）

> **使用方式：** 逐步执行每个测试用例（TC-xx），标记 PASS 或 FAIL。
> **前置条件：** 已在 Chrome 或 Android 设备上运行 App；数据库为空（首次安装）。

---

### TC-01 首次打开 — 空状态
| Item | Content |
|------|---------|
| **Route** | `/` |
| **Steps** | 1. 启动 App<br>2. 观察时间轴主页面 |
| **Expected** | 显示今天的时间轴；整点有刻度线（0:00, 6:00, 12:00, 18:00 可见）；当前时间有指示线；时间轴无事件块；顶部显示"今天剩余 Xh Ym"；有 FAB 悬浮按钮；空状态有友好提示（如"今天还是空白，记一笔吧"） |
| **Notes** | 首次安装，数据库为空 |

## 附录

### 路由汇总
| Route | 页面 | 说明 |
|-------|------|------|
| `/` | 时间轴主视图 | 默认页，展示今天 |
| `/tags` | 标签管理 | 增删改查标签 |

### 事件状态流转图
```
notStarted ──(开始计时/手动标记)──→ inProgress ──(停止)──→ completed
     │
     └──(当天结束未开始)──→ 自动顺延到次日 (仍为 notStarted)
```
