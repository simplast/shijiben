# 8-bit 组件设计模式调研报告

> 调研时间：2026-06-10
> 调研目标：探索主流 8-bit / 像素风格 App 的组件设计模式，为事记本提供参考

## 1. 核心组件设计模式

### 1.1 按钮（Button）

**经典 8-bit 按钮样式**：

```
普通态：
┌─────────────────┐
│  像素虚线边框    │
│  ┌───────────┐  │
│  │  PRESS ME │  │  ← 深色文字 + 浅色填充
│  └───────────┘  │
│                 │
└─────────────────┘

按压态：
┌─────────────────┐
│  像素虚线边框    │
│  ┌───────────┐  │
│  │  PRESS ME │  │  ← 浅色文字 + 深色填充
│  └───────────┘  │
│  ▓▓▓▓▓▓▓▓▓▓▓▓  │  ← 底部像素阴影
└─────────────────┘
```

**事记本当前方案**：
- 直角矩形（0dp 圆角）
- 彩色背景 + 像素虚线边框
- 按压时 scale(0.97) 或背景色加深
- ✓ 符合像素风格核心

**可增强的模式**：

```
A. 经典游戏按钮（带像素"阴影"）
┌─────────────────────┐
│  ┌───────────────┐  │  ← 主按钮（浅色填充）
│  │   START GAME  │  │
│  └───────────────┘  │
│    ░░░░░░░░░░░░░    │  ← 底部像素投影
└─────────────────────┘

B. 像素图标按钮
┌─────────┐
│   ▲     │
│  ▲▲    │  ← 像素图标
│ ▲▲▲   │
└─────────┘

C. 文字链接按钮
[ START ] → 方括号 + 像素文字
```

### 1.2 卡片（Card）

**层级体系**：

```
一级卡片（高突出）：
┌─────────────────────────┐
│  3dp 像素虚线边框        │
│  (DeepNavy / 深色)       │
│  内边距 16-20dp          │
│  背景色（彩色/白色）     │
└─────────────────────────┘

二级卡片（内容区）：
┌──────────────────────┐
│  2dp 像素虚线边框      │
│  (主题色)             │
│  内边距 12-16dp       │
│  背景色（浅色/白色）   │
└──────────────────────┘

三级卡片（内嵌）：
┌────────────────┐
│  1dp 像素虚线边框 │
│  (浅灰色)       │
│  内边距 8dp    │
└────────────────┘
```

**事记本当前实现**（✓ 优秀）：
- 概览卡：3dp navy 边框（一级）
- 待办/已完成：2dp 彩色边框（二级）
- 徽章/标签：1dp navy 边框（三级）

**补充建议**：

```
左边缘条增强：
┌─┬───────────────────┐
│ │ 卡片标题           │  ← 5dp 彩色左边条
│ │ 卡片内容           │
│ │                   │
└─┴───────────────────┘

应用：
- 待办区：AmberOrange 左边缘 ✓
- 进行中：HotPink 左边缘
- 推荐区：CoralRed 左边缘
```

### 1.3 输入框（Input）

**像素风格输入框设计**：

```
普通态：
┌─────────────────────────┐
│  2dp 像素虚线边框         │
│  ┌───────────────────┐  │
│  │ 请输入事件名称...    │  │
│  └───────────────────┘  │
│  浅灰色 placeholder       │
└─────────────────────────┘

聚焦态：
┌─────────────────────────┐
│  3dp 像素虚线边框         │
│  (主题色 + 加粗)          │
│  ┌───────────────────┐  │
│  │ 正在输入中...       │  │
│  └───────────────────┘  │
│  光标：像素方块闪烁       │
└─────────────────────────┘
```

**事记本当前方案**：
- 白色背景 + 2dp Lavender 像素虚线边框
- HotPink "+" 号图标
- AmberOrange 提交按钮
- ✓ 视觉识别度高

**可优化**：
- 聚焦时边框加粗到 3dp 并变色
- 添加像素方块光标闪烁动画
- 空态时显示像素风 placeholder

## 2. 对话框与导航组件

### 2.1 对话框（Dialog / Modal）

**经典像素对话框样式**：

```
╔════════════════════╗
║   确认删除此事件？  ║  ← 标题
╠════════════════════╣
║                    ║
║  此操作不可撤销。    ║  ← 内容
║                    ║
║  [确认]    [取消]   ║  ← 按钮
╚════════════════════╝
```

**设计要点**：
- 双像素边框（外层粗 + 内层细）
- 顶部标题 + 分隔线
- 底部按钮行
- 遮罩：半透明像素图案（可选）

**事记本可应用场景**：
- 删除确认对话框
- 设置弹窗
- 事件详情弹窗

### 2.2 底部导航（Bottom Navigation）

**像素风格底部导航**：

```
┌─────────────────────────────────────┐
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌─────┐ │
│  │  ▓▓  │ │  ░░  │ │  ░░  │ │ ░░  │ │ ← 图标
│  │  ▓▓  │ │  ░░  │ │  ░░  │ │ ░░  │ │
│  │  首   │ │  周   │ │  月   │ │设  │ │ ← 文字
│  │  页   │ │  报   │ │  报   │ │置  │ │
│  └──────┘ └──────┘ └──────┘ └─────┘ │
└─────────────────────────────────────┘
        ▓▓▓▓▓▓               ← 选中指示器
```

**设计要点**：
- 选中态：彩色填充图标 + 文字
- 未选中：灰色轮廓图标 + 文字
- 顶部 2dp 像素虚线分隔线
- 选中项下方可有彩色像素指示条

**事记本当前状态**：暂无底部导航（单页设计）

### 2.3 Tab 组件

**像素 Tab 样式**：

```
┌───────────────────────────────────┐
│  ┌──────┐  ┌────────┐  ┌──────┐  │
│  │ 今日 │  │ 本周  │  │ 本月  │  │  ← 未选中态
│  └──────┘  └────────┘  └──────┘  │
│             ▔▔▔▔▔▔               │  ← 选中下划线
└───────────────────────────────────┘
```

**选中态变体**：
- 下划线式：底部 3dp 彩色方块
- 填充式：彩色背景 + 白色文字
- 边框式：3dp 像素虚线边框

## 3. 进度与数据展示组件

### 3.1 进度条（Progress Bar）

**像素风格进度条**：

```
样式 A：方块填充
[████████████░░░░░░] 50%

样式 B：像素方块
▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░  6/10

样式 C：分段式
[■■■■■□□□□□] 5/10
```

**设计要点**：
- 使用方块字符或矩形块，不使用圆角
- 完成部分：深色/彩色
- 未完成部分：浅色/灰色
- 文字用像素字体，靠右或居中

**事记本可应用场景**：
- 每日目标进度
- 每周目标进度
- 任务完成率

### 3.2 数据统计卡片

**像素风格统计卡片**：

```
┌─────────────────┐
│  TODAY          │  ← PixelLabel 大写
├─────────────────┤
│                 │
│    ███  6h 32m   │  ← 大号数字
│                 │
│  □ COMPLETED    │
│  △ PENDING      │
└─────────────────┘
```

**事记本当前方案**：
- 概览卡（SkyBlue 背景 + 白色大号数字 + 两个彩色徽章）
- ✓ 视觉层级清晰

### 3.3 徽章 / 标签（Badge / Tag）

**像素风格标签**：

```
方形标签：
┌──────────┐
│  WORK   │  ← 彩色背景 + 白色文字
└──────────┘

左边缘条标签：
█ DAILY
█
█  ← 左边彩色条 + 文字

圆点标签：
● 进行中
○ 已完成
```

**事记本当前实现**（✓ 优秀）：
- 直角方块 + 多彩纯色背景 + 1dp navy 像素虚线边框
- 文字：白色 + PixelLabel 风格

## 4. 无阴影的视觉层次

### 4.1 层级创造方法

**核心原则**：不靠阴影，靠边框、色彩、空间创造层次。

```
方法 1：边框粗细层级
一级: 3dp 深色边框   ← 最高突出
二级: 2dp 彩色边框   ← 内容区
三级: 1dp 灰色边框   ← 内嵌元素

方法 2：色彩对比层级
高饱和色背景 > 低饱和色背景 > 白色背景 > 浅灰色背景

方法 3：空间关系层级
外边距 > 内边距 > 紧凑间距
元素之间的空白越大，层级越独立

方法 4：边框样式层级
双线边框 > 实线边框 > 虚线边框 > 无边框
```

### 4.2 事记本当前层级

```
最突出 ←───────────────────────────→ 最不突出
 进行中卡    概览卡    待办区    已完成区
 (HotPink)  (SkyBlue)  (Amber)   (Mint)
  3dp navy   3dp navy  2dp 彩边  2dp 彩边
```

### 4.3 补充技巧

```
A. 像素"投影"（底部偏移）
┌───────────────┐
│  按钮内容      │
└───────────────┘
  ░░░░░░░░░░░░░   ← 底部 2-3dp 深色偏移

B. 嵌套边框（双层边框）
╔═══════════════╗
║  ┌─────────┐  ║  ← 外层粗边框 + 内层细边框
║  │ 内容    │  ║
║  └─────────┘  ║
╚═══════════════╝

C. 左边缘色条
█┌──────────────┐
█│ 卡片内容     │  ← 左边 5dp 彩色条
█│             │
█└──────────────┘
```

## 5. 事记本组件增强建议

### 5.1 现有组件评估

| 组件 | 当前状态 | 评分 | 建议 |
|------|---------|------|------|
| 卡片 | 已有三级边框体系 | 9/10 | 增加左边缘条的一致性 |
| 按钮 | 彩色方块 + 按压反馈 | 8/10 | 增加文字链接式按钮 |
| 输入框 | 底部输入栏 | 7/10 | 增加聚焦态、光标动画 |
| 徽章标签 | 多彩直角方块 | 9/10 | ✓ 已很完善 |
| 对话框 | 暂无标准样式 | 3/10 | 需新增像素对话框组件 |
| 进度条 | 暂无 | 0/10 | 建议新增（用于目标进度） |
| Tab | 暂无 | 0/10 | 可选（周/月视图切换） |
| 底部导航 | 暂无 | - | 单页 App 暂不需要 |

### 5.2 优先级建议

**高优先级**（提升体验）：
1. 进度条组件 — 用于每日/每周目标展示
2. 对话框组件 — 删除确认、设置弹窗

**中优先级**（增强质感）：
3. 输入框聚焦态优化
4. 像素"阴影"按钮变体

**低优先级**（未来扩展）：
5. Tab 组件
6. 底部导航
