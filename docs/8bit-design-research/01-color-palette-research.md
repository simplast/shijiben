## 1. 经典复古调色板

### 1.1 PICO-8 调色板（16色）

最流行的现代像素艺术调色板，由 Lexaloffle Games 设计，是独立游戏社区的"标准色板"：

```
#000000  ■ 纯黑      #1D2B53  ■ 深紫蓝    #7E2553  ■ 深洋红    #008751  ■ 深绿
#AB5236  ■ 棕        #5F574F  ■ 深灰      #C2C3C7  ■ 浅灰      #FFF1E8  ■ 米白
#FF004D  ■ 红        #FFA300  ■ 橙        #FFEC27  ■ 黄        #00E436  ■ 亮绿
#29ADFF  ■ 亮蓝      #83769C  ■ 靛蓝      #FF77A8  ■ 粉        #FFCCAA  ■ 桃
```

**特点**：暗色调偏暖，适合游戏氛围；色彩饱和度高但不过分刺眼。

### 1.2 NES 调色板（54色可用，每帧最多25色）

```
#7C7C7C  ■ 灰    #0000FC  ■ 蓝    #0000BC  ■ 深蓝    #4428BC  ■ 靛蓝
#940084  ■ 紫    #A80020  ■ 深红  #A81000  ■ 红      #881400  ■ 暗红
#503000  ■ 棕    #007800  ■ 绿    #006800  ■ 深绿    #005800  ■ 暗绿
#004058  ■ 青    #000000  ■ 黑    #BCBCBC  ■ 浅灰    #0078F8  ■ 亮蓝
```

**特点**：色彩偏饱和、对比度高，蓝色和绿色特别鲜明。限制较多，适合极简复古。

### 1.3 Game Boy 调色板（4色）

```
#0f380f  ■ 最深    #306230  ■ 深    #8bac0f  ■ 浅    #9bbc0f  ■ 最浅
```

**特点**：极简单色阶，绿色调。高辨识度，立即联想到 Game Boy。适合极简主义设计。

### 1.4 CGA 调色板（4色模式）

```
模式1: #000000  ■ 黑    #55FFFF  ■ 青    #FF55FF  ■ 洋红  #FFFFFF  ■ 白
模式2: #000000  ■ 黑    #555555  ■ 深灰  #AAAAAA  ■ 浅灰  #FFFFFF  ■ 白
```

**特点**：高对比度，粉彩色调，强烈的"早期电脑"感。

```

#FFB347  ■ AmberOrange  - 待办区
#E8F8F0  ■ MintLight    - 已完成卡片背景
#FFD93D  ■ StarYellow   - 装饰/星星

基础主色 (3色)：

#F5EEDF  ■ WarmGray200  - 分割线
#E8DED0  ■ WarmGray300  - 禁用态
#9A8E7E  ■ WarmGray500  - 辅助文字
```

### 3.2 优势分析

- ✓ 色彩丰富且和谐，模块区分清晰
- ✓ 饱和度适中，不刺眼
- ✓ 暖灰阶统一质感，避免冷灰的"廉价感"
- ✓ DeepNavy (#1A1A2E) 替代纯黑，更有温度
- ✓ 语义色映射已初步建立（成功=Mint、警告=Amber、错误=Coral）

### 3.3 优化建议

#### A. 增加明暗变体

每个主色增加深色版（按压态）和浅色版（悬停/背景）：

```kotlin
// 明暗变体建议
val PixelSkyBlueDark  = Color(0xFF5BA5D5)    // 按压态
val PixelSkyBlueLight = Color(0xFF9BD5F5)    // 悬停态

val PixelHotPinkDark  = Color(0xFFE55B8D)    // 按压态
val PixelHotPinkLight = Color(0xFFFF8BBD)    // 悬停态

val PixelTealDark     = Color(0xFF3DB9A8)    // 按压态
val PixelTealLight    = Color(0xFF7DD9C8)    // 悬停态

val PixelCoralDark    = Color(0xFFE87A5B)    // 按压态
val PixelCoralLight   = Color(0xFFFFA08B)    // 悬停态
```

#### B. 明确语义色 Token

```kotlin
object SemanticColors {
    val Success = AccentMint       // #7DD3A8 — 完成、成功提示
    val Warning = AccentAmber      // #FFB347 — 警告、注意
    val Error   = AccentCoral      // #FF8A6B — 错误、删除
    val Info    = PixelSkyBlue     // #6BC5F5 — 信息、提示
    val Active  = PixelHotPink     // #FF6B9D — 进行中状态
    val Pending = PixelLavender    // #C4B5E0 — 待办状态
}
```

#### C. 深色模式准备

```
┌─────────────┬──────────────────┬──────────────────┐
│ Token       │ 浅色模式          │ 深色模式          │
├─────────────┼──────────────────┼──────────────────┤
│ 页面背景     │ WarmGray50       │ #121218          │
│ 卡片背景     │ White            │ #1E1E2A          │
│ 主边框       │ DeepNavy         │ #8888AA          │
│ SkyBlue     │ #6BC5F5          │ #7BD5FF (提亮)   │
│ HotPink     │ #FF6B9D          │ #FF7BAD (提亮)   │
│ CoralRed    │ #FF8A6B          │ #FF9A7B (提亮)   │
│ 辅助文字     │ WarmGray500      │ #8A8A9A          │
└─────────────┴──────────────────┴──────────────────┘

深色模式策略：
1. 背景从暖白 → 深蓝黑（保持暖调，避免纯黑）
2. 多彩色略微提亮以补偿深色背景
3. 边框从深色 → 中灰（反转层级关系）
4. 暖灰阶需要完整的深色版本
```

## 4. 色彩层次与视觉权重

### 4.1 色彩视觉重量排序

```
从最重到最轻：

重量级 ████████████████████████████████████████████
  ■ DeepNavy     ████████████████████████  最重 — 边框、强调
  ■ CoralRed     ██████████████████       高饱和暖色 — 吸引注意
  ■ HotPink      █████████████████        高饱和冷色 — 活跃感
  ■ AmberOrange  ███████████████          中等饱和 — 警示
  ■ Teal         ██████████████           中等饱和 — 平静
  ■ SkyBlue      █████████████            低饱和 — 信息性
  ■ Lavender     ████████████             低饱和 — 辅助性
  ■ StarYellow   ██████████               高亮 — 装饰性
  ■ MintLight    ████████                 最轻 — 背景性
```

### 4.2 色彩使用原则

```
┌────────────────────────────────────────────────┐
│  重要操作 → 重色按钮 (CoralRed / AmberOrange)   │
│  次要操作 → 轻色按钮 (Teal / SkyBlue)          │
│  背景区域 → 最轻色 (MintLight / WarmGray)       │
│  边框层级 → DeepNavy > 彩色 > 灰色              │
└────────────────────────────────────────────────┘
```

### 4.3 无障碍对比度检查

```
白色文字 on 彩色背景（WCAG AA 标准）：
┌──────────────┬────────┬──────────┬────────────────┐
│ 背景色        │ 对比度  │ WCAG AA  │ 建议            │
├──────────────┼────────┼──────────┼────────────────┤
│ DeepNavy     │ 16.2:1 │ ✓ 通过   │ 可用白色文字    │
│ HotPink      │  3.1:1 │ △ 大字OK │ 大号标题可用    │
│ CoralRed     │  2.9:1 │ ✗ 不足   │ 用 DeepNavy 文字│
│ Teal         │  2.5:1 │ ✗ 不足   │ 用 DeepNavy 文字│
│ SkyBlue      │  2.3:1 │ ✗ 不足   │ 用 DeepNavy 文字│
│ Lavender     │  1.9:1 │ ✗ 不足   │ 用 DeepNavy 文字│
│ AmberOrange  │  2.1:1 │ ✗ 不足   │ 用 DeepNavy 文字│
└──────────────┴────────┴──────────┴────────────────┘

规则：
- 大号文字（>18sp 加粗）可用 3:1 对比度
- 小号文字需要 4.5:1，在浅色背景上用 DeepNavy 文字
- 在 DeepNavy 背景上可以放心用白色文字
```

## 5. 2024-2026 色彩趋势

### 5.1 主流趋势

1. **策展调色板 > 严格限制** — 不再追求 16 色限制，而是精心挑选 8-16 色作为核心
2. **暖色调回归** — 从冷色调科技风转向暖色调（暖灰、奶油白、珊瑚色）
3. **渐变暗许** — 严格像素艺术仍然禁止渐变，但"Neo-Retro"风格允许微妙色彩过渡
4. **高饱和 + 低饱和共存** — 强调色用高饱和，背景用低饱和，创造层次
5. **深色模式成为标配** — 像素风格 App 也需要完整的深色模式支持

### 5.2 对事记本的启示

- ✓ 当前暖灰阶符合趋势
- ✓ 9 色策展调色板是合理的规模
- △ 需要补充深色模式色板
- △ 可以增加明暗变体丰富交互层次
- △ 无障碍对比度需要关注（部分浅彩色背景上白色文字对比度不足）
