# 8-bit 动画与交互设计调研报告

> 调研时间：2026-06-10
> 调研目标：探索 8-bit 像素风格 App 的动画与交互设计模式

## 1. 帧式动画基础

### 1.1 核心原则：帧式而非平滑

**经典 8-bit 动画特点**：
- 固定帧率（8-30 FPS）
- 帧与帧之间瞬间切换，无插值过渡
- 动画循环简短（2-8 帧最常见）
- 用最少帧数表达最大信息

```
对比：

平滑动画（现代）：
Frame 1: ████░░░░░░
Frame 2: █████░░░░░
Frame 3: ██████░░░░
...    （每帧前进 1 像素，连续）

帧式动画（8-bit）：
Frame 1: ████░░░░░░  (40%)
Frame 2: ███████░░░  (70%)  ← 跳变，无中间帧
Frame 3: ██████████ (100%)
```

### 1.2 常见帧率选择

```
┌──────────────┬──────┬──────────────────────┐
│ 帧率          │ FPS  │ 适用场景              │
├──────────────┼──────┼──────────────────────┤
│ 超慢          │  2   │ 指示灯闪烁            │
│ 慢            │  4   │ 呼吸、心跳、慢速循环   │
│ 标准          │  8   │ 大多数 UI 动画        │
│ 快            │  12  │ 按钮反馈、状态切换     │
│ 超快          │  24  │ 特效、过渡（少用）     │
└──────────────┴──────┴──────────────────────┘
```

**事记本当前方案**：
- 呼吸灯：约 2 FPS（800ms 循环）
- 按压反馈：瞬时 + 弹簧回弹
- ✓ 符合 8-bit 帧式美学

### 1.3 动画循环模式

```
A. 单向循环（Restart）
Frame 1 → 2 → 3 → 1 → 2 → 3 ...
用于：旋转、闪烁

B. 往返循环（Yoyo）
Frame 1 → 2 → 3 → 2 → 1 → 2 ...
用于：呼吸、膨胀、脉冲

C. 一次性（One-shot）
Frame 1 → 2 → 3 → 停
用于：状态切换、按钮反馈

## 2. 微交互设计

### 2.1 按钮反馈

**像素风格按钮反馈模式**：

```
模式 A：颜色翻转（经典）
正常:  ┌──────────┐
       │  PRESS   │  ← 浅底深字
       └──────────┘

按压:  ┌──────────┐
       │  PRESS   │  ← 深底浅字（瞬间切换）
       └──────────┘

模式 B：像素"下沉"
正常:  ┌──────────┐
       │  按钮    │
       └──────────┘
       ░░░░░░░░░░    ← 底部"投影"

按压:  ┌──────────┐
       │  按钮    │  ← 按钮下移 2dp，投影缩短
       └──────────┘
       ░░░░░░░░

模式 C：缩放（事记本当前方案）
正常: size = 100%
按压: size = 97%  ← 轻微缩小
```

**事记本当前方案**：
- 按压时 scale(0.97) + 背景色变化
- ✓ 简洁有效，不破坏像素感

### 2.2 状态切换动画

**状态切换帧式动画**：

```
待办 → 进行中：
Frame 1: [ ] 待办事件
Frame 2: [■] 待办事件   ← 边框变粗
Frame 3: ▓▓▓ 进行中     ← 背景色填充 + 文字变化

进行中 → 已完成：
Frame 1: 进行中卡片（HotPink）
Frame 2: 闪烁一下（白）
Frame 3: 已完成卡片（Teal）
```

### 2.3 数字变化动画

**像素数字滚动/跳变**：

```
模式 A：逐帧跳变（计数器风格）
12 → 15:
  12  (Frame 1)
  13  (Frame 2)
  14  (Frame 3)
  15  (Frame 4)

模式 B：像素滚动（8-bit 复古）
  ┌──┐
  │12│  ← 数字从上往下滚动
  │  │
  │15│
  └──┘

模式 C：闪烁更新
正常: 03:25
更新: ████  ← 全亮一下
      03:30  ← 新数值
```

**事记本可应用**：
- 计时数字的实时更新
- 统计数字的变化效果

## 3. 加载与过渡动画

### 3.1 加载指示器

**像素风格加载动画**：

```
样式 A：像素点跳动
●   ●   ●
  ● ● ●
   ●●●
  ● ● ●
●   ●   ●  ← 循环

样式 B：进度条前进
[█░░░░░░░]
[██░░░░░░]
[████░░░░]
[██████░░]
[████████]  ← 循环

样式 C：旋转方块
■ □ □
□ □ □
□ □ ■  ← 方块沿四角旋转

样式 D：像素文字
LOADING.
LOADING..
LOADING...
LOADING.   ← 点数量循环
```

**事记本应用场景**：
- 数据加载状态
- 导出/导入进度
- 同步状态

### 3.2 页面转场

**像素风格页面过渡**：

```
样式 A：像素百叶窗
████████████░░░░░░░░░░░░  ← 从上往下
████████████████████░░░░
████████████████████████

样式 B：左右滑入
旧页面 → 新页面
(像素方块，非平滑滑动)

样式 C：渐入渐出（帧式）
Frame 1: 旧页面 (100%)
Frame 2: 50% 旧 + 50% 新 (棋盘格)
Frame 3: 新页面 (100%)

样式 D：黑场切换
Frame 1: 当前页面
Frame 2: 全黑（1 帧）
Frame 3: 新页面
```

### 3.3 抖动过渡（Dithering）

**用抖动图案模拟渐变过渡**：

```
Frame 1: ████████████  (100% 旧状态)
Frame 2: █▓█▓█▓█▓█▓  (75% 旧)
Frame 3: ▓░▓░▓░▓░▓░  (50% 旧)
Frame 4: ░▒░▒░▒░▒░▒  (25% 旧)
Frame 5: ▒▒▒▒▒▒▒▒▒▒  (100% 新)
```

**应用场景**：
- 颜色渐变过渡
- 淡入淡出效果
- 状态变化提示

## 4. 交互设计模式

### 4.1 触摸反馈

**像素风格触摸反馈**：

```
A. 缩放反馈（事记本当前方案）
按压: 0.97x
释放: 回弹

B. 颜色翻转
按压: 背景色 <-> 文字色
释放: 恢复

C. 像素"印记"
按压: 底部出现 2dp 深色条（像素投影）
释放: 消失

D. 帧式闪烁
按压: 1 帧白闪
释放: 恢复
```

### 4.2 列表交互

**像素风格列表操作**：

```
A. 左滑删除
┌─────────────────┐
│  事件名称        │ ◀── 向左滑
│           [删除] │ ← 露出删除按钮
└─────────────────┘

B. 长按选中
┌─────────────────┐
│  ■ 事件名称     │  ← 出现像素复选框
└─────────────────┘

C. 拖拽排序
┌─────────────────┐
│  ⇅ 事件一        │  ← 拖拽手柄
├─────────────────┤
│     事件二        │
└─────────────────┘
```

### 4.3 下拉刷新
```

```
## 5. 声音设计

### 5.1 芯片音乐风格音效

**8-bit 音效类型**：

```
┌─────────────────────────────────────────┐
│ 效果类型    │ 示例            │ 用途     │
├────────────┼─────────────────┼─────────┤
│ 短促"哔"    │ ~800Hz 方波     │ 按钮点击  │
│ 上升音阶    │ Do Re Mi Fa     │ 成功/完成 │
│ 下降音阶    │ Fa Mi Re Do     │ 失败/取消 │
│ 滴答声      │ 短脉冲          │ 计时器    │
│ 提示音      │ 两音组合        │ 通知     │
└────────────┴─────────────────┴─────────┘
```

### 5.2 音效使用原则

**对生产力 App 的建议**：

1. **默认关闭**：音效默认为关闭，用户可主动开启
2. **简洁短促**：每个音效 < 200ms，不打断思路
3. **低频轻柔**：避免高频刺耳的方波
4. **重要操作才有声**：不要每个按钮都响

### 5.3 事记本可应用场景

- 开始/停止计时：短促"哔"声
- 完成事件：上升音阶
- 删除事件：下降音阶（可选）
- 达到每日目标：简短胜利旋律

## 6. 事记本动画增强建议

### 6.1 现有动画评估

| 动画效果 | 当前状态 | 评分 | 建议 |
|---------|---------|------|------|
| 呼吸灯闪烁 | 有，800ms循环 | 8/10 | ✓ 已很好，可增加更多帧 |
| 按钮按压缩放 | 有，0.97x | 8/10 | ✓ 符合风格 |
| 列表项动画 | 暂无 | 3/10 | 增加进入动画 |
| 页面转场 | 默认 | 5/10 | 可尝试帧式转场 |
| 数字变化 | 实时更新 | 6/10 | 可增加跳变效果 |
| 加载状态 | 默认 | 3/10 | 建议新增像素加载器 |

### 6.2 优先级建议

**高优先级**（低投入高回报）：
1. 列表项进入动画（帧式淡入）
2. 完成事件的成功反馈动画
3. 加载状态像素动画

**中优先级**（增强氛围）：
4. 页面转场（帧式）
5. 数字跳变效果
6. 可选音效

**低优先级**（锦上添花）：
7. 下拉刷新像素动画
8. 成就解锁动画
```
