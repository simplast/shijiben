# 事记本（ShiJiBen）设计文档

> 日期：2026-06-22（持续更新）
> 状态：V1 原型稳定

## 一、产品定位

### 是什么

一个纯粹的本地时间记录工具。受《奇特的一生》启发，核心理念是：**单纯地记录生活，不设 TODO、不强迫复盘，让记录本身成为习惯。** 通过长期记录，自然看见时间和精力花在哪里，不对自己评判，减少内耗。

### 不是什么

- 不是日历应用、不是 TODO 应用、不是复盘应用
- 不是计划清单、不是时间管理、不是任务管理、不是打卡应用
- 不联网、无社区、无提醒推送

### 核心哲学

1. **记录即审视**：未经审视的人生不值得一过。记录是审视的前提。如果每做两件事之间都要犹豫、墨迹、准备很久，就会形成空白。目的是减少空白。
2. **App 反映现实，不评判现实**：事情没做就是没做，这个事实应该可见。预写的事件如果没做，顺延到明天——不是 nagging，是诚实。不让一件事彻底消失在意识之外。
3. **轻量存在**：时间可视化静静在那，不制造焦虑。打开 App 感受到的是平静和掌控感，不是压力。

## 二、技术架构

### 技术选型

- **平台**：Android 原生应用
- **语言**：Kotlin
- **UI**：Jetpack Compose
- **架构**：MVVM + Repository 模式
- **本地存储**：Room（SQLite 抽象层）
- **依赖注入**：Hilt
- **异步**：Kotlin Coroutines + Flow
- **导航**：Jetpack Navigation Compose

### 设计原则

- 数据模型简单，不过度抽象。Event 和 Note 是独立表，不强行合并。
- 8-bit 美学集中在 `core/theme`，不散落各处。
- 本地优先：所有数据在设备上，不依赖任何网络。

## 三、数据模型

### Event（事件）

| 字段 | 类型 | 说明 |

| updatedAt | Long | |

### 事件状态自动推算

状态不由用户手动设置，由 save() 根据事实自动推算：

| 条件 | 状态 |
|------|------|
| duration = 0 | not_started |
| duration > 0, 现在 < start + duration | in_progress |
| duration > 0, 现在 > start + duration | completed |

**自动顺延机制**：

- App 打开时检查，把之前日期的 `not_started` 事件移到今天（start_time 改为次日相同时刻）
- 不做后台定时（符合本地、不联网原则）
- 目的：不让预写的事情彻底消失在意识之外

## 四、核心 UI：时间轴

### 布局

- **左侧时间条**：24 个小色块（每小时一格），按 **8 色彩虹循环**着色
  - 有事件记录时 = 饱和彩虹色，已过去未记录 = 半透明褪色，未来 = 浅灰
  - 当前小时有红色边框标记
- **右侧事件列表**：**单行紧凑卡片**，标题（左）+ 时间范围 + 耗时 badge（右）
- **背景**：像素山水图（alpha 0.2 弱化），裁剪铺满
- **顶部日期栏**：下方有 4dp 彩虹像素装饰条
- **右下角悬浮加号按钮**：统一记录入口

### 8-bit 美学

- **色板**：**彩虹 + 黑白灰**。仅允许彩虹色（红橙黄绿蓝紫粉）和纯黑/纯白/不同明度灰色，无中间色
- **组件**：直角、硬阴影、点阵字体
- **字体**：使用开源像素字体 Fusion Pixel Font（SIL OFL 1.1 协议，可免费商用），支持中英文
- **滑块**：6 色彩虹循环方块（无蓝色），光标为亮粉紫，选中/未选中用饱和/褪色区分
- **背景**：像素山水景观图作首页底层背景，alpha 0.2 弱化不干扰内容
- **集中管理**：`ui/theme` 中定义色板常量、像素边框组件、字体配置

## 五、记录流程

所有记录通过右下角悬浮加号按钮进入。

### 新增事件弹窗

- 标题输入框（新增时自动聚焦、弹窗动画完成后弹出键盘；编辑时**不**弹出键盘）
- 开始时间选择器（像素风格刻度滑块，光标固定在中央拖拽轨道滚动，5点-24点，±3h 窗口，**6 色彩虹方块**）
- 持续时间选择器（像素风格刻度滑块，20分-3小时，**6 色彩虹方块**）
- Yes / No 按钮
- 编辑时无"删除"按钮、无"状态"按钮（状态由保存时自动推算）

### 事件规则

- duration = 0 → `not_started`（无时间规划的准备事项）
- duration > 0, 现在 < start + duration → `in_progress`（进行中）
- duration > 0, 现在 > start + duration → `completed`（已完成）

## 六、标签系统

- **首次打开**：空标签起步，用户自行创建
- **标签管理**：用户可增删改标签，为每个标签选择 8-bit 色板中的颜色
- **作用**：分类与着色。在时间轴上通过颜色一眼区分事件类型
- **不做**：不做时长汇总统计（v1），不做层级标签

## 七、回看与可视化（V2）

### GitHub 式热力图

- 每一天是一个方块
- **填充 = 记录的时间覆盖比例**：没有记录 = 空白方块；记录了一半时间 = 面积填一半
- 价值：照见"空白"。未记录的时间 = 未审视的时间 = 可能的犹豫和墨迹
- 目的：减少空白，告诉自己"我知道我在做什么，你看，都记录了"

### 时间可视化（轻量存在）

- **今天剩余时间**：打开 App 时静静可见（如"今天还剩 6h 23m"）
- **今年/一生剩余时间**：在单独页面，想看才看
- 不制造焦虑，只是提醒时间在流逝

### 随笔功能（V2 完整化）

- V1 仅支持时间轴右侧点的展示
- V2 补充：随笔的创建入口、列表查看、编辑删除
