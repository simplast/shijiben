## Why

事记本已经完成了第一轮 8-bit 风格改版（多彩色板 + 像素虚线边框 + Press Start 2P 字体），但当前设计系统仍存在几个问题：

1. **图标风格脱节**：首页仍在使用 Material Design 图标（PlayArrow、Delete、Refresh 等），圆角风格与像素方块感完全不搭，视觉上"出戏"
2. **边框"莫名其妙"**：`pixelBorder` 采用虚线方式（4dp 块 + 2dp 间隔），看起来断断续续，缺乏完整感，用户反馈"像没画完"
3. **删除按钮过小**：24dp 方块 + 14dp 图标，视觉权重低，操作不趁手
4. **色彩分布不均**：大面积白/浅色背景，彩色只出现在左边条和小按钮上，"彩虹感"不足
5. **设计语言不统一**：首页、周报、月报、编辑器风格差异较大，缺乏系统性

本轮深化的目标是：**从"有 8-bit 元素"升级为"完整的像素 UI 设计系统"**，确立夏日海边清新感的视觉基调（海蓝+薄荷绿为主，暖黄+珊瑚橙点缀），统一组件规范，替换图标体系，为后续功能迭代打下坚实的设计基础。

## What Changes

### 一、色彩系统：夏日海边青绿色系

从"多彩糖果风"转向"夏日海边清新风"，以蓝绿色系为主基调，减少粉紫色的使用（避免公主风）。

- **主色**：海蓝 + 薄荷绿 + 浅海蓝（蓝绿色系，占据视觉 60%）
- **点缀色**：日光黄 + 珊瑚橙（暖色调点缀，占据 20%）
- **特殊色**：淡粉（仅用于"进行中"状态，少量保留，5%）
- **底色**：奶油白（暖调，15%）
- **深色**：深青蓝（替代纯黑）
- **灰阶**：暖灰阶（保持暖调）

每个主色增加明/暗变体，用于按压态、悬停态、背景态。

### 二、边框系统：双线像素边框

将当前的"虚线边框"升级为"双线边框"——外层主色 + 内层高光，营造复古游戏窗口/对话框的感觉。

- **一级卡片**（概览/进行中）：2dp 主色外线 + 1dp 白色内线
- **二级卡片**（列表区）：1.5dp 主色外线 + 0.5dp 同色系浅色内线
- **三级元素**（按钮/标签）：1dp 双线
- 全部使用实线条，不再使用虚线

### 三、图标系统：纯像素几何图标

核心交互图标全部改为 Canvas 自绘的简单几何形，完全替换 Material Icons。

- **播放/开始**：右向三角形
- **停止**：实心方块
- **删除/关闭**：X 形
- **再来一次**：环形箭头（简化）
- **完成/对勾**：折线
- **待办**：空心菱形
- **星星/收藏**：五角星（简化）
- **更多**：竖排三点
- 等等，共约 12-15 个核心图标

功能/装饰图标可后续引入 Kenney CC0 像素素材补充。

### 四、组件体系化

将散落在 HomeScreen.kt 中的组件抽离为独立的像素 UI 组件库，统一规范：

- `PixelCard`：像素卡片（支持一级/二级/三级变体）
- `PixelButton`：像素按钮（主按钮/次按钮/图标按钮）
- `PixelIcon`：像素图标组件（统一尺寸、颜色规范）
- `PixelSectionHeader`：区块标题
- `PixelInput`：像素输入框
- `PixelDialog`：像素对话框
- `PixelBadge`：像素徽章/标签

### 五、首页视觉重设计

在组件体系化的基础上，重排首页布局，增强"彩虹感"和游戏感：

- 概览卡：海蓝背景 + 白色文字 + 双线边框
- 进行中卡：淡粉背景（特殊状态色）+ 双线边框
- 已完成区：薄荷绿背景 + 左边多彩色条
- 待办区：白色底 + 海蓝双线边框 + 彩色播放按钮
- 整体节奏更紧凑，色彩分布更均匀

## Capabilities

### New Capabilities
- `pixel-ui-design-system`：完整的 8-bit 像素 UI 设计系统——双线边框体系、像素几何图标库、海蓝系夏日色彩、标准化像素组件库。

### Modified Capabilities
- `homescreen-8bit-colorful`：在原有 8-bit 多彩基础上，升级色彩为海蓝系、边框为双线、图标为像素几何、组件体系化。

- `ui/theme/` 新增：**新增** — `PixelIcons.kt`（像素图标库）、`PixelComponents.kt`（像素组件库）、`PixelBorder.kt`（双线边框 Modifier）。
